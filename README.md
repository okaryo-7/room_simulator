# 家具配置シミュレータ

引越し用の家具配置 2D シミュレータです。間取り図の写真から文字を取り除いた間取りを作り、その上に家具を実寸で並べられます。

## 起動

Node.js があれば追加インストールは不要です。

```bash
npm start
```

ブラウザで http://localhost:5173 を開きます。

## 主な機能

- **間取り図の取り込み**: 写真（ファイル選択・ドラッグ＆ドロップ・Ctrl+V 貼り付け）から太い線（壁）だけを残し、文字・寸法線・床の色を除去。しきい値・壁の最小太さ・ゴミ除去・照明ムラ補正をスライダーで調整
- **間取りの修正**: 壁ペン（直線、水平/垂直に吸着）と消しゴム
- **縮尺合わせ**: 長さの分かる壁をドラッグして実寸 (cm) を入力
- **画面操作**: 空白ドラッグで平行移動、ホイールでカーソル位置を中心にズーム
- **図形**: 四角・円/楕円・三角・L字・ドア開閉範囲・文字。名前・寸法を図形内に表示
- **家具プリセット**: 洗濯機・冷蔵庫・ベッド・ソファなど目安の寸法入り。自作プリセットの登録も可
- **編集**: 移動・リサイズ・回転、複数選択、複製、コピー&ペースト、前面/背面、ロック、メモ
- **スナップ**: 5cm グリッドと他の家具の辺への吸着（Alt で一時解除）
- **重なり警告**: 家具同士・壁・ドア開閉範囲との重なりを赤枠で表示
- **計測ツール**: 2 点間の距離を表示
- **レイアウト案**: 複数の配置案を切り替えて比較
- **保存**: ブラウザに自動保存（IndexedDB）、JSON ファイルへの保存/読み込み、PNG 画像出力
- **元に戻す/やり直し**

操作方法はアプリ右上の「？」から確認できます。
