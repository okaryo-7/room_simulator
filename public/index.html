    操作方法

    空白をドラッグ / 中ボタン / Space+ドラッグ画面の平行移動
    ホイールズームイン・アウト（カーソル位置中心）
    図形・プリセットをクリック画面中央に配置（ドラッグで好きな場所へ）
    家具をドラッグ移動（Shift+クリックで複数選択）
    四隅の□ / 上の○サイズ変更 / 回転（Shiftで15°刻み）
    ダブルクリック名前を編集
    矢印キー1cm移動（Shiftで10cm）
    R / Shift+R90°回転
    Ctrl+C / Ctrl+V / Ctrl+Dコピー / 貼り付け / 複製
    Delete削除
    Ctrl+Z / Ctrl+Y元に戻す / やり直し
    V / M / W / E / F選択 / 計測 / 壁ペン / 消しゴム / 全体表示
    Esc選択解除・ツールを選択に戻す

    おすすめの手順

    1. 「間取り図を読み込む」で写真を選び、文字が消えるように調整
    2. 「縮尺合わせ」で、長さが分かる壁の両端をクリックして実寸を入力
    3. 家具プリセットを置き、サイズを自分の家具に合わせて変更
    4. 赤い枠は家具同士・ドア開閉範囲との重なりです
